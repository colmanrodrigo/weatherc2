Probar aumento de tamaño del widget

Método A — contenedor responsivo (prueba primero)

Si el widget es responsive, al aumentar max-width aquí se hará más grande sin perder calidad.

Método B — escalado con transform (si no hay otra opción)

Transform: scale(1.5) aumenta el aspecto, pero puede perder nitidez si el widget es raster.

Prueba ambos métodos y ajusta los anchos / scale según necesites.
